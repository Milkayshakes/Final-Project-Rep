# HMA (Human Made Art)

## Repository
<https://github.com/Milkayshakes/Final-Project-Rep>

## Description
If you have been on the internet, you know that the world is currently ran by AI slop using stories to make the generrated content seem interesting. I want to create a software for real artists and storytellers without the use of AI content. By the end of this I will have a creative format for a storyteller to write their story and a collabrative artist to come in and finish their story with art. 

## Features
- Feature 1
	- This will be a proof of concept with the idea of a collaborative social media site in mind
- Feature 2
	- There will be two roles, there is the writer and the artist (Can of course switch and swap) One of the roles will create a beginning post that is human made. The post will be put on the social platform waiting for collaborative work.
- Feature N 
	- There will be a way to post, formatting for social media, the ability to see posts on the feed, liking, commenting, and a search bar

## Challenges
- Figure out the UI that is similar for both Instagram, Facebook ETC. 
- Figure out a way to have 1-2 people work on a single post
- Figure out simple social media codes, such as uploading, liking, seeing the post etc. 

## Outcomes
Ideal Outcome:
- Have a working proof of concept that the idea will work. AKA show the test run of either a few posts or have a friend help test to show how a single post would work

Minimal Viable Outcome:
- Have the beginning blueprint of a Social Media website with the ability to create posts with a format

## Milestones

- Week 1
  1. Do research on social media UI's, create a similar UI on Python based on it.
  2. Create a way to post images/write for a post, can either show example posts or figure out posting in the test

- Week 2
  1. Create the format of the posts 
  2. Create a feed feature where you can see previous posts

- Week N (Final)
  1. Incorporate other details such as liking, commenting, and a search bar
  2. Test run program and kill any remaining bugs
